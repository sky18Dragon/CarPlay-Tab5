# CarPlay-Tab5 v1.0.0

日期：2026-11-14（Australia/Sydney）。首个版本化发布。目标为 M5Stack Tab5 / ESP32-P4 v1.x；有线 CarPlay，非 Apple 认证产品。

## 功能

- USB 枚举、NCM、USBMUX、Lockdown 配对/TLS、iAP2 与 AirPlay 会话。
- 890×240、目标 16 fps 软件解码，触摸、音乐、导航播报混音、麦克风及 Siri。
- 音量/亮度设置持久化，等待页 Clear pairing 二次确认与退出保护。
- 导航流 ID 回收修复；USB 已停止错误通道完成事件修复，TX/RX 看门狗、端口电源恢复及 15 秒独立任务进度保护。
- SD 日志与崩溃记录、充电控制。
- 合入远端 PCM 饥饿恢复、认证音频包回归及 Required CI；保留现有双路音频与持久化设置。

## 本次整理

- 固件版本集中在 `version.txt`，写入 ESP-IDF 应用描述、启动日志和等待页。
- 删除离线演示、开机音频自测、一次性清理配对维护固件入口和模拟显示分支。
- 合成 H.264 测试素材不再进入应用镜像；保留主机解码回归素材。

- 整理 CMake 源文件清单、双语 README、认证说明和发布脚本。保留已验证的运行参数，不顺带调整解码策略或排查 iPhone 17 换机问题。

## 固件与发布范围

| 构建 | 认证身份 | 能否直接进入 CarPlay | 使用范围 |
|---|---|---|---|
| `local-auth` | 嵌入本机实验性身份 | 在已验证手机上可用，仍需信任/允许连接 | 本地保存，不公开上传 |
| `no-auth` | 不包含身份 | 不能，会停在认证缺失 | 开发、源码构建验证 |

公开仓库中的源码不包含 `secrets/mfi`，公开发布不能自动授权重新分发认证材料。带身份固件可提取私钥；源码许可与认证材料权限分开。具体说明见 [软件认证接入](../软件认证接入.md)。

每个构建生成：

- `carplay-tab5-v1.0.0-<构建>-app.bin`：应用升级，烧录地址 **0x10000**，保留 NVS。
- `carplay-tab5-v1.0.0-<构建>-full.bin`：新设备全量初始化，烧录地址 **0x0**。覆盖引导程序/分区表，并清除覆盖范围内旧配对和设置。
- `manifest.json`：版本、构建选项、构建时 Git 状态、芯片目标、镜像大小和 SHA-256。
- `SHA256SUMS`、完整构建配置、烧录说明及许可证。

发布分区表为 24 KiB NVS + 4 MiB factory。已部署板卡曾使用 8 MiB factory；升级本应用无需改变原有分区表。只有本版 `-full.bin` 的新设备初始化才应用发布分区表。

## 构建和回归

```sh
source <esp-idf-v5.5.3>/export.sh
python3 scripts/fetch_openh264.py
python scripts/release.py --auth local
python scripts/release.py --auth none
./scripts/test_host.sh
./scripts/test_ui.sh
./scripts/test_crypto.sh
./scripts/test_decoder.sh build-release-local-auth
```

发布构建使用独立目录和显式认证开关，避免继承读卡固件、维护模式或开发者私有 sdkconfig。OpenH264 下载固定到提交 `652bdb7719f30b52b08e506645a7322ff1b2cc6f` 并校验每个 Git blob；ESP-IDF 固定 v5.5.3，组件锁定于 `dependencies.lock`。

## 已有实机证据与验收边界

- iPhone 12 Pro Max / iOS 16.1.1：已通过清理、重新信任、CarPlay 视频及音乐。清理按钮复验连续投屏约 4 分钟，2,824 帧无解码/输出错误，音乐 31,017 包无 bad 或采样丢包/乱序；手动拔线返回等待页。
- 导航修复基线：连续约 1 小时 42 分钟、85 次导航播报无拒绝；另一小时采样 100 次导航开流/结束无拒绝，但有一次非人为 USB 断开后恢复，不能称为零掉线。
- USB 恢复基线：受控注入已停止 TX 通道错误、丢 TX 完成、丢 RX 完成，均恢复视频；任务卡死保护经实机验证。
- 上述长稳/故障注入来自版本整理前的同功能基线。v1.0.0 整理后的最终构建与设备验收结果单独记录在[执行记录](../执行记录.md)，不以旧日志替代新镜像验收。

## 已知问题

1. **换机可能需要重启 Tab5。** iPhone 17 Pro / iOS 26.5 在 Clear 后未连接，仅重启 Tab5 后用户确认成功。未取得失败日志，原因未定。本版保留该已知问题。
2. **推荐换机步骤：** 拔旧手机 → Clear pairing → 确认 → 重启 Tab5 → 插入已解锁的新手机 → 确认信任/允许 CarPlay。当前 NVS 容量有限，不保证多手机长期共存。
3. USB 线材/供电和真实偶发错误仍可能导致断开；已有自动恢复不能保证永不掉线。
4. 低分辨率软件解码限制清晰度/帧率，音乐时帧率可能下降；偶发视频内存不足拒收未全部消除。
5. I2S 开流 disable 日志噪声与该板冷启动 other_watchdog 现象仍存在。
6. 电话完整流程、回声消除、续航与低电量保护未完成验证；没有无线 CarPlay。
7. Flash/NVS 未加密，私钥与配对资料不可作为普通发布附件上传；本地日志也可能包含手机屏幕/身份信息。
